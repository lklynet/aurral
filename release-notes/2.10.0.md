2.10.0 adds useful controls for playlists and webhooks. It also makes large library scans and several download and media-service syncs more reliable.

## What's new

- Show track availability for an individual playlist and retry missing tracks from its menu. You can also choose whether each flow or shared playlist records listening history. That setting affects future recommendations and scrobbles without removing plays already recorded.
- Test a configured webhook from the Connect settings page using its current URL, headers, and body. Testing does not change the saved settings.
- Downloads from Deezer, YouTube, Soulseek, and Usenet now use the same track-matching checks. Aurral also checks files after download before marking them complete.
- Turn off the owner-name prefix for synced Navidrome playlist names in the Navidrome behavior settings.

## Fixes worth noticing

- Large library scans no longer stall while reconciling changed files. A forced scan still checks the full library.
- Navidrome playlists sync tracks as soon as they are available, then catch up as the remaining tracks are indexed. Aurral can also recover a saved playlist reference that has gone stale.
- Large Spotify playlists now sync completely. If Spotify returns an incomplete list, Aurral keeps the saved playlist instead of replacing it with partial results.
- Aurral reuses BrainzMASH artist and album metadata longer and backs off during provider rate limits, reducing repeated requests.
- Subsonic clients can authenticate with any local Aurral account. Token authentication also stays current after a password change.

## Things to try

- Turn on **Show track availability** for a playlist, then retry a missing track from its menu.
- Change **Record listening history** for a flow or shared playlist and confirm that future plays follow the new setting.
- Use **Test webhook** on a configured webhook to check its current request without saving settings.
- Turn off the Navidrome playlist name prefix and sync a playlist.
