3.0.0 is the biggest Aurral release yet. There's a full screen player with lyrics, daily mixes and a Playlists page to browse, plugins, a Logs page, and a new navigation to try. Under the hood, Aurral runs its background work on its own job queue, playlists point at your Library instead of keeping their own copies, and media servers pick up playlists from files instead of API syncing. It also idles lighter than 2.13.

## Upgrading from 2.x

- Aurral 3 opens databases that finished upgrading on 2.x. If yours is older, Aurral 3 stops without changing anything and tells you so. Start `ghcr.io/lklynet/aurral:2` once with the same `/config`, wait a few minutes, then switch back.
- Mount your data at `/config`. If the database is only in `/app/backend/data`, Aurral 3 stops and asks you to move the mount.
- On first start, Aurral 3 saves your database as `aurral.pre-job-queue.db` in `/config`. To go back to 2.x, follow [Roll back to Aurral 2](https://docs.aurral.org/admin/troubleshooting/#roll-back-to-aurral-2). Changes made in 3 are lost.
- `AUTH_USER` and `AUTH_PASSWORD` are no longer read. Manage accounts in **Settings > Users**. If you're locked out, [reset the admin password](https://docs.aurral.org/admin/users/#reset-the-admin-password).
- `DOWNLOAD_FOLDER` is now `LIBRARY_FOLDER`. The old name still works with a warning.
- Aurral no longer syncs playlists to Navidrome, Plex, or Jellyfin through their APIs. On upgrade it deletes the playlists it made there, then writes an M3U file for every flow and playlist to `_playlists` in the Library folder. Navidrome and Jellyfin import those on their own, and Aurral sends them to Plex once you connect it in **Settings > Listening > Plex**. If Navidrome shows a playlist twice, delete the older copy there once.
- Sign in with Plex is gone. Users who used it can sign in with a password, Google, or SSO. An admin can set their password in **Settings > Users**.
- The app API is now version 2. Apps built for version 1 need an update. See the [app API contract](https://docs.aurral.org/api/app-contract/).

## What's new

- A full screen player with lyrics, the queue, and a visualizer. Open it from the player bar or press **F**. The player also docks, minimizes to the sidebar, shows synced lyrics, levels loud tracks, and has stop and favorite buttons.
- Start radio from any track, album, or artist, and turn on autoplay to keep playing when the queue ends.
- Your queue follows you. Pause on one device and pick up on another, including Subsonic clients like Feishin and Symfonium.
- **Your mixes** on Library home builds Daily Mixes, On Repeat, Rewind, Rediscover, and more from your plays each day. **Made for you** sits on Discover, and the Playlists page lets you browse by genre, mood, and decade. Nothing downloads until you save one.
- Plugins add menu actions, events, download sources, playlist imports, and schedules without putting them in core. Install them in **Settings > Plugins**. See [Plugins](https://docs.aurral.org/admin/plugins/).
- **Settings > Status > Logs** shows what went wrong and groups repeated problems. **Copy problems** gives you something to paste into an issue, and there's a prompt you can hand to an agent to triage your logs.
- Try the new navigation in **Settings > Appearance > Navigation**. Each section gets tabs in the top bar, and the sidebar lists your playlists and flows.
- Static playlists now point at tracks in your Library instead of owning their own downloads. A track in three playlists is one file.
- Import M3U playlists and Spotify Liked Songs like any other playlist. Tracks you already own reuse their files. Navidrome favorites can come in too, and favorites now shape recommendations.
- Search finds songs by name and your playlists.
- Album pages are one page whether you own the album or not. Multi-disc albums show disc headings and disc titles from MusicBrainz, which Subsonic clients get too.
- Tracks keep their featured artists, and downloads are tagged with genres.
- Every user gets their own API key in **Settings > Profile > API access**.
- Webhooks pick their own events, and there are new events for added artists and tracks.
- Admins set **Default permissions** for new users in **Settings > Users**.
- Flow tracks no longer wait in review. Aurral drops a file it can't verify and tries the next one.
- Every Library track has **Re-search > Manual**. **Keep this file** is gone. Tracks marked with it become unmonitored, which also stops upgrades.
- Add a cookies file for yt-dlp to get past YouTube's bot check.
- Hide YouTube videos on artist pages from **Settings > Appearance**. The Blocklist moved to **Settings > Listening**.
- The installed app feels native on iPhone.

## Fixes worth noticing

- Soulseek searches no longer throw away their results or get stuck behind searches Aurral already dropped.
- Large BrainzMash albums finish downloading instead of retrying forever.
- Tracks with no known length no longer pile up in review.
- Album downloads show every track in Activity and one History row.
- Adding hundreds of albums at once no longer fails most of them.
- Release-day downloads start within the hour.
- Tidarr downloads each album once instead of once per quality.
- Albums with more than 100 tracks show every track right away.
- The Library loads up to 5x faster on slow connections.
- Open tabs reload after a server update instead of breaking.

## Things to try

- Press **F** while something plays.
- Open **Your mixes** on Library home after a day of listening.
- Turn on the new navigation in **Settings > Appearance > Navigation**.
- Look at **Settings > Status > Logs**.
- Start radio from an artist you love.
