3.1.0 moves every Aurral install to AurralBrainz, the metadata server we build and run for Aurral at `data.aurral.org`. Artist pages, album pages, genres, and search all come from it now. They load faster, and Aurral asks far less of everyone else's servers. Album pages flag their popular tracks, Spotify and Deezer imports match tracks by ISRC, search and profiles play previews, and a long list of download fixes landed too.

**Please update now, whatever version you're on.** This is the release every install needs:

- **On 2.x**, discovery and Wrapped break on December 1. That's when the Last.fm API starts needing Last.fm Pro. Read **Upgrading from 2.x** in the [3.0.0 notes](https://github.com/lklynet/aurral/releases/tag/v3.0.0) before you jump.
- **On 3.0.x**, Aurral gets its metadata from `brainzmash.kell.ly`, and that server shuts down on November 30. After that, search breaks, and so does every artist or album page Aurral hasn't already saved. No setting or environment variable keeps 3.0.x working, so updating is the fix.

AurralBrainz runs on my own infrastructure and Cloudflare, and every Aurral install uses it. Aurral is free, with no paid tier, and I want to keep it that way. If Aurral has earned a spot in your day, [sponsoring on GitHub](https://github.com/sponsors/lklynet/) or [buying me a coffee](https://buymeacoffee.com/lkly) pays for these servers and keeps them fast. Huge thanks to everyone who already does.

## Before you update

- Aurral clears the metadata it cached from the old server, so pages load fresh once after the update.
- If you pointed the metadata **Base URL** at your own BrainzMash server, clear it. Open Settings and search for **Metadata**. AurralBrainz uses a different format, so a BrainzMash server won't work. `BRAINZMASH_BASE_URL` is no longer read. To run your own copy of the AurralBrainz files, use `METADATA_BASE_URL`.
- If your network only lets Aurral reach hosts you've allowed, add `data.aurral.org`.

## What's new

- Metadata comes from AurralBrainz, built daily from MusicBrainz, ListenBrainz, and the Cover Art Archive. A first visit to an artist page used to make six calls to outside services. Now it makes one. A search across artists, albums, and songs is one request instead of three. An artist too new to have a file yet comes straight from MusicBrainz.
- Album pages mark up to three popular tracks with a flame. Artist pages show listener counts, the Popular list expands in place, and release cards show their listeners.
- Spotify and Deezer playlist imports match each track by its ISRC, so tracks arrive knowing their recording, album, and artist. They skip the name guessing, and a single lands on the album it came from.
- Songs you don't own play a 30-second preview from search, and a song top result gets a **Preview** button. Top tracks on friend and profile pages play as previews too.
- Coming back to Aurral on the web after playing on Aurral Pocket or a Subsonic client keeps your web queue. A devices button in the player offers **Pick up from** the other device, with the track and where it stopped.
- The Releases page and the **Recent & upcoming releases** rail list your Library artists' releases first in each month. Recommended artists only add albums and EPs, so their singles no longer bury the artists you follow.

## Fixes worth noticing

- Albums that share a title, like Weezer's self-titled records, get their own folders, such as `Weezer (2001)` and `Weezer (Teal Album)`. Clean up splits folders that two albums already share. A media server may see a moved album as new.
- Aurral no longer grabs a Usenet release again after its download failed.
- Torrents with files named only by track number, like `03.flac`, import instead of failing and getting replaced by lossy files.
- When Aurral can't remove a download's original file after copying it into the Library, it keeps the import and warns about folder permissions, instead of importing the same file up to five times.
- Aurral no longer queues an upgrade for a track whose file you already replaced outside Aurral, and an upgraded track shows the source its new file came from.
- After a partial Deemix album download, the missing tracks can still download one by one from the same release.
- `WEBFLAC` counts as a FLAC release, a Usenet group tag no longer counts as the track title, and Aurral never searches for tracks MusicBrainz titles `[unknown]`.
- A Library watcher that fails starts again by itself and scans its folder to catch up, instead of leaving automatic watching off.
- The Beat visualizer pulses for playlist and flow tracks.

## Things to try

- Open an album and look for the flames.
- Import a Spotify playlist and check that its singles land on the right albums.
- Search for a song you don't own and play its preview.
- Play something on Aurral Pocket, then open Aurral on the web and pick it up from the devices button.
