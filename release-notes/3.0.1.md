3.0.1 gets metadata and search working again. BrainzMash's public relay stopped answering Aurral, which broke search and every artist or album page Aurral hadn't already saved. Aurral now gets its metadata from a BrainzMash server we run ourselves. This release also stops the Lidarr plugin from adding albums you never asked for, and fixes bitrates in View info.

## Fixes worth noticing

- Search, artist pages, and album pages load again. Aurral now uses `brainzmash.kell.ly`, a BrainzMash server run by the Aurral maintainers. Everything Aurral already saved carries over, so nothing has to load again after you update.
- Older installs saved the relay's address as their metadata **Base URL**. Aurral clears it, so they move to the new server too. A server you set yourself stays as it is.
- Flows, playlists, and single-track requests no longer go to Lidarr. The Lidarr plugin only downloads whole albums, so a single flow track sent to it added and monitored its whole album in Lidarr. Now Lidarr only gets albums you request. Update the Lidarr plugin to 0.3.0 in **Settings > Plugins** to get this. Albums it already added stay in Lidarr.
- View info shows track bitrates in kbps. It used to show them 1000 times too high.

## Things to try

- Search for an artist you've never opened in Aurral, then open their page.
- If you use the Lidarr plugin, update it in **Settings > Plugins** and check that your next flow refresh adds nothing to Lidarr.
- Can't update yet? Set `BRAINZMASH_BASE_URL=https://brainzmash.kell.ly`, then search Settings for **Metadata** and clear **Base URL** to get search back on 3.0.0.
