The first run creates your admin account, chooses where your music lives, and offers your listening history and services to connect. Everything after the account is optional and stays in Settings.

## Before you start

Complete [Filesystem and mounts](/getting-started/storage/) first. In short:

- Mount the same host media folder in Aurral and in the services that you use.
- Use the same container path in each service, usually `/data`.
- Keep Aurral's `/config` mount separate.

## Complete setup

1. Open Aurral. Enter a username and password for the admin account.
2. If you are the only user on a home network, turn on **Auto-login on local network**. See [Local-network auto-login](/admin/users/#local-network-auto-login).
3. Under **Your music**, choose the music you already have, if any:
   - **Read in place** plays the files where they are and never changes them.
   - **Import** copies them into the Library folder. The originals stay put.
4. Set the **Library folder**, such as `/data/downloads/aurral`. Aurral keeps the music it adds here.
5. Under **Connect**, add listening history from Last.fm, ListenBrainz, or Spotify, and import plays from Navidrome, Plex, or Jellyfin. Each opens its Settings page. Select **Go to Aurral** when you are done.
6. Open **Settings > Status > Storage** and select **Run checks**. Fix each failed check.

**Storage health** checks that Aurral can read your files and write to the Library folder. Its **Aurral-native playback** section checks that the built-in player can read indexed media.

Aurral also runs a Subsonic server at `/rest`. Subsonic players can connect to it with an Aurral account. See [Navidrome and Subsonic](/integrations/navidrome/).

## Connect the other services

- **Download clients.** Open **Settings > Downloads**. Connect slskd, SABnzbd, NZBGet, Tidarr, or deemix, and make sure that each client writes completed files under the shared media mount. The built-in yt-dlp source needs no separate service.
- **Navidrome, Plex, or Jellyfin.** Add the Library folder to a music library in the server. Navidrome and Jellyfin also import Aurral's playlist files. To send playlists to Plex or import your plays from a server, open **Settings > Listening**. See [Navidrome](/integrations/navidrome/), [Plex](/integrations/plex/), and [Jellyfin](/integrations/jellyfin/).
- **Lidarr.** Add its root folder as a read-only folder, and install the Lidarr plugin to download through it. See [Lidarr](/integrations/lidarr/).

If a service uses a different path, see [When paths cannot match](/getting-started/storage/#when-paths-cannot-match). Mount the folder inside Aurral before you add a path mapping.
