---
title: Flows
description: How a flow picks tracks, and the settings that control it.
---

A flow is a playlist that Aurral builds again on a schedule. Aurral downloads flow tracks as temporary files under `_flows` in the Library folder. Its playlist file lets Navidrome and Jellyfin show the flow without adding the files to the Library.

![Aurral flow editor](../../../../../web/screenshots/flow-editor.webp)

Select **Edit flow** on a flow to open the flow editor. It lists your flows on the left, so you can switch between them. Changes save as you make them. A text field saves when you leave it. A flow has four groups of settings:

1. **Mix** sets where the tracks come from and how many each source adds.
2. **Schedule** sets when the flow runs.
3. **Filters** limits every source to tags and release years, and can leave tags out.
4. **Playlist** turns the flow on or off and sets the [flow options](#flow-options).

## Start from a template

Select **New flow** and choose a template or **Custom**:

- **Discover Weekly** picks from your recommendations.
- **Trending Mix** picks from trending artists.
- **Library Blend** picks from artists in your Library.
- **Listening History** follows artists you've played recently. It appears only when Aurral has listening history for you.
- **Release Radar** picks one track from each recent album you don't have yet.

A template turns on and builds its first mix right away. You can change its recipe afterwards. **Custom** opens the editor with the flow turned off, so you can set it up first.

Turning a flow off removes its tracks and stops its schedule. It keeps its settings, and turning it back on builds a new mix.

## Mix

Set how many tracks each source adds. A source set to 0 is off. The flow's size is the total.

| Source           | Tracks come from                                                                                                                 |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Discover         | A rotating pick from your top recommendations. Excludes library artists, blocked artists, and blocked genres.                    |
| Library          | Artists in your Library, skipping tracks you already have.                                                                       |
| Trending         | This week's trending tracks. Excludes library artists, blocked artists, and blocked genres.                                      |
| Artists and tags | Artists similar to the ones you pick or to your recent listening. Excludes library artists, blocked artists, and blocked genres. |
| New releases     | One track from each recent album by a library artist that you don't have yet.                                                    |

When a flow's tracks come from different places, the tracklist shows why Aurral picked each one, such as "Similar to Pusha T" or "Trending this week".

## Filters

Filters apply to every source that is turned on.

- **Only these tags** keeps artists that carry at least one of the tags. Spelling variants match, so `hip-hop` and `hip hop` are the same tag.
- **Skip these tags** leaves out artists that carry any of the tags, such as `christmas`. It works with or without **Only these tags**.
- **Released** keeps tracks from releases that first came out in that range. Leave a year blank for no limit.

Year range examples:

- `1980` to `1989` for one decade
- `2020` to blank for 2020 and later
- blank to `2000` for 2000 and earlier

Narrow filters can leave a source with fewer matches than you asked for. Aurral fills the gap from your other sources, and otherwise makes a shorter playlist. The flow's track count shows how many tracks it found.

To enter several tags or artists, separate them with commas. Aurral turns the text into entries after each comma, or when you leave the field. It ignores duplicates.

## Artists and tags

**Artists and tags** finds artists outside your Library from three kinds of seeds:

- **Similar to** artists you pick.
- **Also use my recent listening**, which uses the artists you've played most recently each time the flow runs.
- The tags in **Only these tags**, which it also searches by.

It needs at least one of these. It takes turns between them, starting with the closest matches for each.

## Schedule

Pick the days when the flow can run and the hour of those runs.

## Deeper cuts

**Deeper cuts** changes which tracks Aurral takes from each artist. When it is off, Aurral uses the artist's top 10 tracks. When it is on, Aurral uses tracks 10 to 25. If an artist has too few tracks in that range, Aurral falls back to the top 10.

## Flow options

Set these options in the **Playlist** group of the flow editor:

- **Download automatically** downloads new tracks each time the flow runs. Turn it off to see the picks first: tracks you already have stay playable, and the rest wait as **Not downloaded** and play a 30-second Deezer preview. Previews never count as plays. Download one from its track menu, or all of them with **Download** in the flow menu. A new flow starts with this off when no download source is set up, and a flow without a download source always waits.
- **Scrobble plays** controls whether Aurral records plays from this flow in your listening history. Turn it off to keep these plays out of your recommendations and your scrobbling services. Plays recorded before the change stay.
- **Show in Library** adds the flow's current tracks to the Library pages. It is off by default. A track leaves the Library when it rotates out of the flow, when you turn the option off, or when you delete the flow. Aurral does not move or copy the files. Your playback servers do not change.

## How a flow runs

When a flow runs, Aurral:

1. Collects candidates for each source that is turned on, keeping only tracks that match your tags and years.
2. Picks the playlist with one song per artist.
3. Moves any shortfall in one source to the other sources.
4. Sends the playlist to the download worker, unless **Download automatically** is off.

A track that fails to download stays failed until you re-search it or the flow runs again. See [Playlist imports](/using/playlist-imports/#download-retries-and-failures).

## Keep flow tracks

Each run replaces the flow's tracks, including ones you downloaded from it.

- To keep one track in the Library, select **Add to library** in the track menu, or favorite it.
- To save all finished tracks as a static playlist, select **Save as playlist** in the flow menu. Aurral names the new playlist after the flow, with `Static` at the end.

## Replace a flow track

To replace a finished track that Aurral downloaded, right-click it and select **Re-search**:

- **Automatic** lets Aurral search for and choose a new recording.
- **Manual** opens a search in one download client. You choose the result. See [Choose a download yourself](/using/activity/#choose-a-download-yourself).

The current file stays available until the replacement passes Aurral's checks.

## Lidarr import list

Each flow can publish a URL that Lidarr reads as a **Custom List**. Copy it with **Copy Lidarr import URL** in the flow menu. See [Lidarr: Import list feeds](/integrations/lidarr/#import-list-feeds).
