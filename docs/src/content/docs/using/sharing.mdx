---
title: Sharing
description: Share tracks, albums, artists, and playlists, with optional playback and file imports between Aurrals.
---

Share a track, album, artist, or playlist with anyone, including people who do not run Aurral. Open its share action from the Library, Discover, a playlist's menu, or the player.

New shares use a short link with a 16-character code. Existing long links continue to work.

## Choose what to share

By default, a share includes names and the available track list. The link opens on aurral.org with artwork, streaming-service links, and previews where Deezer has a matching track. Your Aurral does not need to stay online for these details to work.

Turn on **Share my files** to let people play the available music from your Library. Aurral opens a temporary Cloudflare tunnel for those files, keeping your server's address hidden. Your server must stay running for full playback.

Sharing files or playlists requires signing in to an account. Sign in to manage links in your Profile too. Without an account, links share details only and cannot be stopped from the app.

**Allow downloads** also lets people download original files or copy them into their own Aurral. A playlist can include tracks whose files you do not have. Its full track list is still shared, and available files are identified separately.

Set when file access expires, then select **Create link** and **Share link**. On a phone or a browser with a share menu, Aurral opens that menu. Otherwise it copies the link.

Shares hold a snapshot of the selected music. Changes to a playlist or new releases added to an artist do not add music to an existing share. Create another link to share those additions. A share can include up to 2,000 tracks. Files from flows are never shared.

## Import into your Aurral

The **My Aurral** menu keeps three actions separate. **Open in my Aurral** finds the artist, album, or track in your own Library, or opens discovery or search when you do not have it. It does not import anything. **Import details only** and **Import shared files** open the import review with that choice selected. Playlist shares offer the two import actions.

Enter your Aurral address the first time you use an action. Your browser remembers it for next time, including an app base path. The address is never sent to aurral.org. Use **Change** in the menu to switch Aurrals.

You can also select **Import share** in your Library, or **Import Aurral share** in the Playlists menu, and paste a link.

Review the item on your own Aurral before importing:

- **Details only** saves the names and track list without starting downloads or enabling monitoring. An artist import saves the artist. A playlist import keeps its order and repeated entries.
- **Include shared files** copies available files when the sender permits downloads. Aurral reuses music already in your Library. Tracks without a shared file remain as details only.

File transfers appear in Activity. If a transfer fails, retry it when the sender's share is online. A failed transfer does not start a search or switch to another download service. Copying shared files does not require Lidarr or a download integration. Each imported file can be up to 2 GiB.

Imported playlists are independent copies. They do not sync with the sender. If a playlist's name is already taken, Aurral adds a number to the imported name.

## File access and stopping a share

When file access expires or the sender goes offline, the share keeps its details and available previews. People can still import the details.

Your links are listed in **Profile → Shared links**. **Stop sharing** removes the hosted details and ends access to your files. It does not remove details or files someone has already imported or downloaded.

The Docker image includes `cloudflared`, which file sharing needs. If you run Aurral another way, install it on your server. Aurral opens one tunnel while file shares are active and closes it when none remain. Cloudflare offers quick tunnels without an uptime guarantee, so playback can be temporarily unavailable.

## What is shared

Aurral stores the shared names, MusicBrainz IDs, and track list on aurral.org. It does not upload your audio there. Playback and downloads travel through your server's temporary tunnel.

Links contain random codes identifying the share. They contain no server address, username, credentials, or local file paths. Anyone with the link can read its details and use the file access you allow, so treat it like any message you send.

Older share links continue to work. Older artist listen links include albums added later, following their original behavior.
