Aurral is free, MIT licensed, and isn't going to lock basic features behind a paid pro tier. Keeping the project alive and running the shared infrastructure that lets thousands of installs work with zero API keys still costs real time and real money.

## What sponsorship pays for

- Ongoing maintenance, bug fixes, and releases
- **AurralBrainz** (`data.aurral.org`), the hosted metadata and search service that powers artist pages, album details, and catalog search out of the box
- Extra cloud capacity when personal hardware isn't enough to absorb traffic spikes

AurralBrainz runs on the maintainer's own infrastructure and Cloudflare, built from open [MetaBrainz](https://metabrainz.org/) data. Sponsorship directly helps keep it fast and reliable.

## Become a sponsor

If Aurral replaced a monthly streaming bill for you, consider throwing a few bucks back at the project through [GitHub Sponsors](https://github.com/sponsors/lklynet/) or [Buy Me a Coffee](https://buymeacoffee.com/lkly).

Sponsorship is always optional. Filing good bug reports, improving the docs, or helping people out in [Discord](https://discord.gg/cpPYfgVURJ) helps just as much.
