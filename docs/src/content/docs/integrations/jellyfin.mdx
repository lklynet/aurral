title: Jellyfin
description: Point Jellyfin at the Aurral Library folder and its playlist files, and import Jellyfin plays.
---

Jellyfin is optional. Jellyfin scans the Library folder and imports the playlist files that Aurral writes for every flow and static playlist. Aurral does not connect to Jellyfin for this. To bring your Jellyfin plays into Wrapped and recommendations, connect it in **Settings > Listening**.

## Setup

1. Mount the same media root in Aurral and Jellyfin, at the same container path. See [Filesystem and mounts](/getting-started/storage/).
2. In Jellyfin, add the Library folder, for example `/data/downloads/aurral`, to a music library. It can be its own library or an extra folder in your existing one.
3. If playlists reuse tracks from Lidarr, make sure the Lidarr root folder, such as `/data/music`, is in a Jellyfin music library too.
4. Turn on **Enable real time monitoring** for the library, so Jellyfin picks up changes without a scheduled scan.

## Playlists

Aurral writes an M3U file for each enabled flow and each static playlist to `aurral-weekly-flow/_playlists` in the Library folder. **Settings > Library > Playlist files** shows the folder.

- Jellyfin imports each file as a playlist that every Jellyfin user can see.
- Jellyfin applies a change a minute or two after the file changes. Aurral writes each changed file again a few minutes later, so tracks that Jellyfin was still indexing appear too.
- The files list each track by its full path in Aurral. Jellyfin must see the Library folder and the Lidarr root folder at the same paths.
- When a playlist is deleted or its flow is turned off, Aurral removes its file and Jellyfin removes the playlist.

Edit these playlists in Aurral, not in Jellyfin.

## Listening history

Jellyfin keeps no play history that Aurral can read on its own. The **Playback Reporting** plugin records it.

1. In the Jellyfin dashboard, install **Playback Reporting** from the plugin catalog, then restart Jellyfin.
2. In the dashboard, open **API Keys** and create a key for Aurral.
3. In Aurral, open **Settings > Listening > Jellyfin**.
4. Enter the **Server URL**, your Jellyfin **Username**, and the **API key**.
5. Select **Connect Jellyfin**.

Aurral imports the plays that Playback Reporting recorded for that user, then checks for new plays every hour. Playback Reporting starts recording when it is installed, so plays from before then are not imported. Each Aurral user connects their own Jellyfin username. Only admins can connect a server. **Disconnect** removes the plays that Aurral imported.

## Bring a Jellyfin playlist into Aurral

Jellyfin cannot export a playlist as M3U on its own. Use a Jellyfin plugin or client that exports M3U files. Then, in Aurral, open **Library > Playlists**, open the create menu, select **Import playlist**, and select **M3U**.
