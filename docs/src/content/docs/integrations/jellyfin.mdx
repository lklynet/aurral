---
title: Jellyfin
description: Publish Aurral flows and static playlists to Jellyfin.
---

Jellyfin is optional. Aurral publishes its playlists into an existing Jellyfin music library through the Jellyfin API. It does not create a Jellyfin library or start playback.

A Jellyfin playlist can only hold tracks from a Jellyfin library. Aurral downloads playlist and flow tracks into its Downloads Folder, so that folder must be inside a Jellyfin music library. It can be its own library, or an extra folder in your existing music library. You do not need to move your music.

## Setup

1. In Jellyfin, add the Aurral Downloads Folder to a music library and scan it.
2. In Jellyfin, create an API key that can read the music library.
3. In Aurral, open **Settings > Playback > Jellyfin**.
4. Enter the **Server URL** and the **API key**.
5. Enter a **User ID**. Aurral uses this Jellyfin user for older playlists that have no Aurral owner.
6. If Aurral and Jellyfin see the files at different paths, add a mapping in **Settings > Downloads > Remote path mappings**, with **Applies to** set to **Jellyfin**. A mapping only translates paths. It does not add a folder to a Jellyfin library.
7. Select **Test connection**.
8. Open **Settings > Status > Storage** and select **Run checks**. The **Jellyfin playback** section shows whether Jellyfin scans the Downloads Folder.

## How Aurral publishes playlists

Aurral creates or updates a Jellyfin playlist for each enabled flow and static playlist when you save the settings or when the playlist changes. When you delete a playlist or turn off a flow, Aurral deletes the Jellyfin playlist that it created.

Aurral looks for a Jellyfin user with the same username as the Aurral owner of the playlist. The match ignores case. Aurral creates the playlist as a private playlist of that Jellyfin user. If no Jellyfin user matches, Aurral does not publish the playlist.

## Edit a playlist in Jellyfin

You can add songs to an Aurral playlist in Jellyfin or in a client such as Feishin. Aurral keeps your additions when it updates the playlist, but they do not appear in Aurral.

To remove a song that Aurral added, remove it in Aurral. If you remove it only in Jellyfin, Aurral can add it again at the next update.

When you delete a flow or static playlist in Aurral, or turn off a flow, Aurral deletes its Jellyfin playlist, including your additions.

## Matching and scans

Aurral reads the audio library of the matched Jellyfin user. It finds each track by its exact path in Jellyfin first. If the path does not match, it uses the MusicBrainz recording ID, but only when exactly one track has that ID. It never guesses by title or artist. Aurral publishes only the tracks that it finds, so a missing track does not stop the rest of the playlist.

When you change the Jellyfin settings, Aurral updates the playlists and starts a library scan in the background. Other settings changes do not start this update. When files change, Aurral tells Jellyfin which folders changed. It does not scan every Jellyfin library. If a changed folder is outside every Jellyfin music library as Jellyfin sees it, Aurral reports all music libraries instead and logs a warning. A Jellyfin path mapping fixes this. When more than 20 folders change at once, Aurral reports the music libraries that hold them. Changes made close together share one request. Jellyfin picks up the changes after about a minute. If Jellyfin is still indexing files, Aurral retries the incomplete playlists for about 15 minutes.
