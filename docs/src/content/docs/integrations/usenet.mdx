---
title: Usenet (Prowlarr and SABnzbd or NZBGet)
description: Usenet-backed downloads for flows and playlists.
---

Usenet downloads use **Prowlarr** for indexer searches. They use **SABnzbd** or **NZBGet** as the download client.

Aurral treats each download client equally. You must configure only one download client for Usenet operation.

Enable and connect both components:

- The download client in **Settings > Download clients**
- Prowlarr in **Settings > Indexers**

## Setup overview

1. Run Prowlarr with at least one Usenet audio indexer configured.
2. Run SABnzbd or NZBGet with a category Aurral can use (default `aurral`).
3. Mount the same media root in Aurral and SABnzbd or NZBGet at the same container path so Aurral can read completed files ([Filesystem and mounts](/getting-started/storage/)).
4. Open **Settings > Indexers**.
5. Enable **Prowlarr**.
6. Enter the Prowlarr URL and API key.
7. Select **Test connection**.
8. Select **Refresh indexers**.
9. Enable each indexer.
10. Set the priority for each indexer.
11. Open **Settings > Download clients**.
12. Enable **SABnzbd** or **NZBGet**.
13. Enter the URL and credentials.
14. Select **Test connection**.
15. Settings save automatically after each change.

## Prowlarr

Open the **Prowlarr** card under **Indexers**:

- **Server URL**: URL Aurral can reach (for example, `http://prowlarr:9696` in Docker)
- **API key**: from Prowlarr
- **Music categories**: Newznab audio categories (default `3000`)
- **Result limit**: max releases returned per search

After the connection test, Aurral shows the Usenet indexers from Prowlarr.

Open each card. Set **Priority**. A lower number has a higher priority.

## SABnzbd

Open the **SABnzbd** card under **Download clients**:

- **Server URL**: URL Aurral can reach (for example, `http://sabnzbd:8080` in Docker)
- **API key**: from SABnzbd
- **Category**: SABnzbd category for Aurral jobs (default `aurral`)
- **Source priority**: relative to slskd. The default is `20`. The slskd default is `10`.
- **Add NZBs paused**: send jobs to SABnzbd in a paused state

Aurral monitors SABnzbd until the download is complete. Aurral then imports the best audio file into the Aurral Downloads Folder.

## NZBGet

Open the **NZBGet** card under **Download clients**:

- **Server URL**: URL Aurral can reach (for example, `http://nzbget:6789` in Docker)
- **Username** and **Password**
- **Category**: NZBGet category for Aurral jobs (default `aurral`)
- **Source priority**: relative to slskd (default `20`)
- **NZB priority**: queue priority passed to NZBGet
- **Completed download path**: optional override when Aurral cannot infer the finished-file location
- **Add NZBs paused**: send jobs to NZBGet in a paused state

Aurral monitors NZBGet until the download is complete. Aurral then imports the best audio file into the Aurral Downloads Folder.

If NZBGet runs on Windows and reports host paths, mount the parent folder into Aurral.

Then, add a path mapping under **Settings > Download clients > Remote Path Mappings**.

Aurral can find a track with an incorrect duration. Aurral retains this track under **Activity > Queue**.

You can preview, approve, or deny the track.

## Quality and upgrades

Use **Settings > Download clients > Quality profile** to set acceptable quality tiers and the preferred cutoff. Aurral reads the completed audio file before it accepts the quality. A quality rejection does not go to Queue review.

Usenet can supply both missing tracks and upgrades. Upgrade searches follow the normal source priority and have a lower queue priority than missing-track downloads. See [Playlists: Track upgrades](/using/playlists/#track-upgrades).

## Download source priority and fallback

Aurral can run slskd, Usenet, and yt-dlp at the same time. Each source has a **source priority**. Aurral tries lower numbers first.

If a source fails, Aurral tries the next source for the same track.

Change the priorities if you want Aurral to try Usenet or yt-dlp first.

## History

When you configure Usenet, **History** shows a separate **SABnzbd** or **NZBGet** tab for flow and playlist download jobs.

See [Activity](/using/activity/).
