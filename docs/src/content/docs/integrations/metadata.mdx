---
title: Metadata and search
description: Where Aurral gets artist and album data, and how to point it at another metadata server.
---

Aurral gets artist pages, album details, release dates, genres, and catalog search from BrainzMash, a hosted service built on MusicBrainz data. Most installations need no setup.

When BrainzMash has no data for an item, Aurral asks other services. For example, it uses Deezer for artist images and previews, and Last.fm for tags. It uses the Deezer ID from the BrainzMash links when one exists, so it does not have to search Deezer by name.

## Use another metadata server

To use your own BrainzMash server:

1. Open `/settings/metadata`. This page is not in the Settings navigation.
2. Enter the server address in **Base URL**.

Leave **Base URL** empty to use the hosted service. You can also set the address with the `BRAINZMASH_BASE_URL` environment variable. A value in Settings takes precedence.
