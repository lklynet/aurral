---
title: Metadata and search
description: Where Aurral gets artist and album data, and how to point it at another metadata server.
---

Aurral gets artist pages, album details, release dates, similar artists, top tracks, and genre lists from `data.aurral.org`, static JSON files built daily from MusicBrainz and ListenBrainz by the Aurral maintainers. Catalog search goes through the same host. Most installations need no setup.

When an artist or album is too new to have a file on `data.aurral.org` yet, Aurral fills the gap straight from MusicBrainz. It still uses Deezer for previews and as a fallback for artist artwork, top tracks, or related artists when the metadata files do not have them.

## Use another metadata server

To point Aurral at your own copy of the metadata files:

1. Open Settings and search for **Metadata**. This section is not in the Settings navigation.
2. Enter the server address in **Base URL**.

Leave **Base URL** empty to use `https://data.aurral.org`. You can also set the address with the `METADATA_BASE_URL` environment variable. A value in Settings takes precedence.
