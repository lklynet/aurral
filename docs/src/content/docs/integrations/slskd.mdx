slskd downloads flow and playlist tracks from Soulseek. Aurral can also use [Usenet](/integrations/usenet/) through Prowlarr and SABnzbd/NZBGet.

![Aurral history with slskd downloads](../../../assets/screenshots/history.webp)

## Setup

1. Mount the same media root in Aurral and slskd at the same container path. See [Filesystem and mounts](/getting-started/storage/).
2. Connect slskd in **Settings > Download clients > slskd**.

The API key is optional. Leave it empty when slskd runs with authentication disabled - for example `SLSKD_NO_AUTH=true`, `--no-auth`, or `web.authentication.disabled: true` - such as when an authenticating reverse proxy sits in front of slskd.

Aurral uses the slskd API and reads the completed files from the path slskd reports. It checks the reported byte count and decodes the audio before it moves the file into your Downloads Folder path. If a file fails either check, Aurral retries another candidate or download source.

If you already have a partial file from an earlier run, delete it and retry the track from the flow or artist page.

If slskd runs on Windows and reports host paths, mount the parent folder into Aurral. For example, slskd can report `N:\...`.

Then, add a path mapping under **Settings > Download clients > Remote Path Mappings**.

## Worker settings

Open the **slskd** card in **Settings > Download clients**. Set these options:

- **Source priority**: order relative to Usenet (default `10`)
- **Clean up after runs**: clear completed slskd jobs when a flow or playlist run finishes

Use **Settings > Download clients > Quality profile** to select and order FLAC, MP3, and M4A quality tiers. Aurral uses this profile for new downloads and upgrades. See [Playlists: Quality profile](/using/playlists/#quality-profile).

slskd can supply both missing tracks and upgrades. Aurral reads the completed file before it accepts the quality.

## Download fallback

When Usenet or yt-dlp is also configured, Aurral tries sources in priority order. If slskd fails, Aurral can fall back automatically. See [Usenet](/integrations/usenet/#download-source-priority-and-fallback) and [yt-dlp](/integrations/ytdlp/).
