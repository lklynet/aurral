slskd is a Soulseek client. Aurral uses it to download tracks for flows, playlists, and Aurral albums. For an Aurral album, Aurral can download one whole folder at once when the folder fits the requested release.

![Aurral history with slskd downloads](../../../assets/screenshots/history.webp)

## Setup

1. Mount the same media root in Aurral and slskd, at the same container path. See [Filesystem and mounts](/getting-started/storage/).
2. Open **Settings > Download clients > slskd**.
3. Turn on **Enable slskd**.
4. Enter the **Server URL** and the **API key**.
5. Select **Test connection**.

The API key is optional. Leave it empty when slskd runs without authentication, for example with `SLSKD_NO_AUTH=true`, `--no-auth`, or `web.authentication.disabled: true`. Use this only when a reverse proxy that requires sign-in sits in front of slskd.

Aurral reads each completed file at the path that slskd reports, and moves it into the Downloads Folder.

If slskd runs on Windows and reports host paths such as `N:\...`, mount the parent folder in Aurral. Then add a mapping in **Settings > Download clients > Remote path mappings**, with **Applies to** set to **slskd**.

## Options

- **Source priority** sets the order among download sources. The default is `10`.
- **Clean up after runs** clears finished slskd transfers when a flow or playlist run ends.

To choose the accepted FLAC, MP3, and M4A tiers, open **Settings > Download clients > Quality profile**. See [Quality profile](/using/playlists/#quality-profile).

slskd can supply missing tracks and upgrades. Aurral reads each downloaded file before it accepts the quality.

## How Aurral searches

When Aurral knows the artist, it searches for the artist and the album first. If that gives too few usable results, it searches for the album title alone, then for the album and track titles together. Without an artist, Aurral starts with the album title alone. Aurral checks every result against the requested track and checks every downloaded file before it accepts it.

## Fallback

When other sources are configured, Aurral tries them in priority order. If slskd fails, Aurral tries the next source. See [Download source priority and fallback](/integrations/usenet/#download-source-priority-and-fallback).
