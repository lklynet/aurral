Ticketmaster is optional. Aurral shows nearby events for recommended, popular, and library artists.

![Aurral nearby shows](../../../assets/screenshots/shows.webp)

## Setup

Add your Ticketmaster consumer key in **Settings > Connect > Ticketmaster**.

When you enable shows, users can use automatic location detection. Users can also enter a ZIP or postal code with a country so non-US codes resolve correctly.
