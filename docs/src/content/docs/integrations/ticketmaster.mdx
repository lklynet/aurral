Ticketmaster is optional. Aurral shows nearby events for recommended, popular, and library artists.

![Aurral nearby shows](../../../assets/screenshots/shows.webp)

## Setup

Add your Ticketmaster consumer key in **Settings > Connect > Ticketmaster**.

When you enable shows, users can use automatic location detection. Users can also enter a ZIP code or postal code. For postal codes shared by multiple countries, enter the two-letter country code as well, such as `FR` for `75001` in France.
