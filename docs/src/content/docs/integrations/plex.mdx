title: Plex
description: Point Plex at the Aurral Library folder, send it Aurral playlists, and import Plex plays.
---

Plex is optional. Plex scans the Library folder like any other music folder. Connect Plex in **Settings > Listening > Plex** to send Aurral's playlists to it and to bring your Plex and Plexamp plays into Wrapped and recommendations.

## Setup

1. Mount the same media root in Aurral and Plex, at the same container path. See [Filesystem and mounts](/getting-started/storage/).
2. In Plex, add the Library folder, for example `/data/downloads/aurral`, to a music library. It can be its own library or an extra folder in your existing one.
3. If playlists reuse tracks from Lidarr, add the Lidarr root folder, such as `/data/music`, to the same Plex music library.
4. In the Plex server settings, turn on **Scan my library automatically**, so Plex picks up new files on its own.

## Connect the server

An admin connects the server once.

1. Open **Settings > Listening > Plex**.
2. Enter the **Server URL**, such as `http://plex:32400`.
3. Select **Sign in with Plex** and sign in with the Plex account that owns the server.

This also imports the owner's plays.

## Playlists

With **Send playlists** on, Aurral adds every enabled flow and static playlist to Plex and updates it when the playlist changes. The playlists belong to the server owner's Plex account.

- Plex reads each playlist file at the path Aurral wrote it, so Plex has to see the Library folder and the Lidarr root folder at the same paths as Aurral. If it can't find any of the tracks, **Settings > Listening > Plex** shows an error.
- Deleting or renaming a playlist, or turning off its flow, removes it from Plex. So do turning off **Send playlists** and **Disconnect server**.
- Aurral finds its playlists in Plex by name. A playlist you made in Plex with the same name as an Aurral playlist is replaced.

## Listening history

Once the server is connected, each Aurral user can import their own Plex plays.

1. Open **Settings > Listening > Plex**.
2. Select **Sign in with Plex** and sign in with your Plex account. It must have access to the server.

Aurral imports the music plays of that account, then checks for new plays every hour. **Disconnect** removes the plays that Aurral imported.

If an admin connects a different Plex server, each user disconnects Plex and signs in again.

## Bring a Plex playlist into Aurral

Plex cannot export a playlist as M3U on its own. [plex2pl](https://github.com/tx3stn/plex2pl) with `"outputFormat": "m3u"` writes an M3U file for each Plex music playlist. Then, in Aurral, open **Library > Playlists**, open the create menu, select **Import playlist**, and select **M3U**.
