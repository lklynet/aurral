---
title: Last.fm
description: Use Last.fm for recommendations, listening history, and scrobbling.
---

Last.fm is optional. A Last.fm API key gives Aurral similar artists, tags, and top tracks, which improve recommendations, discover playlists, and flows. Flow **Deep Dive** needs the key.

Aurral reads artist genres from BrainzMash first. It uses Last.fm tags only for artists that BrainzMash has no genres for.

## Add the API key

An admin adds the Last.fm **API key** and **API secret** in **Settings > Connect > Last.fm**. Aurral uses the key for discovery data. It uses the key and the secret together to connect scrobbling accounts.

## Scrobble to Last.fm

1. Open **Settings > Playback > Scrobbling**.
2. Turn on **Last.fm**.
3. Select **Connect Last.fm account**.
4. Approve access in the Last.fm window.

Aurral stores a Last.fm session key for each user. Navidrome is not required.

Each user connects their own account while signed in. The instance API key cannot connect an account, because it does not identify a user.

## Per-user listening history

Each user chooses a history source in **Profile > Listening history**. To read Last.fm history, choose **Last.fm** and enter a Last.fm username. To use only the plays recorded in Aurral, choose **Local only**.

When a user chooses Last.fm, ListenBrainz, or Koito, Aurral combines the provider's history with the plays recorded in Aurral.

## How Aurral sends plays

Aurral records each play from the built-in player and from Subsonic clients before it contacts Last.fm. If Last.fm is down, playback continues and Aurral keeps the play.

Aurral queues each play and retries temporary failures. Because of the retries, Last.fm can receive the same play twice. Aurral's own history does not depend on the result.

## Discovery settings

An admin sets the refresh interval and the discovery mode in **Settings > Discover**. The modes are Safer, Balanced, and Deeper.

If Last.fm is unavailable, users can choose ListenBrainz or [Koito](/integrations/koito/) as their history source in **Profile**.
