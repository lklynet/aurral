title: deemix
description: Download tagged tracks and albums from Deezer through deemix.

[deemix](https://github.com/bambanah/deemix) is a self-hosted Deezer downloader. It returns tagged files with cover art. Aurral can use it as a download source for flows, playlists, and Aurral albums.

Aurral talks to the deemix web server. For an Aurral album, it picks the Deezer album that matches the requested tracks and adds one album URL to the deemix queue. For a flow or playlist track, it adds one track URL. Aurral imports only the files that pass its checks.

Aurral does not store your ARL. Sign in once in the deemix web UI. Aurral reuses that sign-in through the deemix API.

deemix uses the address that you configure, which is usually plain HTTP on your own network. Keep deemix on a network that you trust, or put it behind HTTPS if the connection leaves that network.

## Setup

1. Run deemix, open its web UI, and sign in with your ARL.
2. Open **Settings > Download clients > deemix**.
3. Turn on **Enable deemix**.
4. Set **Server URL** to your deemix address, for example `http://localhost:6595`.
5. Choose a **Bitrate**. FLAC is the default.
6. If necessary, set **Source priority**. The default is `15`.
7. Select **Test connection**.

Your Deezer plan must allow the bitrate. FLAC needs a lossless plan, and MP3 320 needs a high-quality plan. If the bitrate is above your plan, **Test connection** warns you. deemix refuses those downloads. It does not lower the quality.

## Path mapping

deemix writes files to its own download folder. Aurral must read the same files.

Mount the deemix download folder in Aurral at the same path. If you cannot, add a mapping in **Settings > Download clients > Remote path mappings**, with **Applies to** set to **deemix**. Use the path that deemix reports as **Remote path**, and the path inside Aurral as **Local path**.

Aurral moves each checked file into the Downloads Folder. A file that fails the checks stays outside the Library.

## Behavior

Aurral tries download sources in priority order. It ranks Deezer results by title, artist, album, and duration. It skips tracks that your account cannot stream.

Aurral checks each downloaded file in the same way as files from other sources. It then writes the title, artist, album, album artist, year, and track number into the file.

For an Aurral album, Aurral searches Deezer for the album and checks each matching album's tracklist against the missing tracks. A deluxe or remastered edition counts as the same album. Aurral queues the album whose tracklist covers the most missing tracks.

If an album download finishes with errors, Aurral assigns the finished files to their tracks. The missing and failed tracks continue one by one through the other sources. One file never fills two tracks.

A track that fails Aurral's checks is not offered again for that request.

If a file matches the requested track but its duration is very different, Aurral holds it in **Activity > Queue**. You can preview, approve, or deny it.

Aurral removes a track from the deemix queue before it imports the file or holds it for review. It removes an album from the queue after it processes the album. A new request can then start a new download.

If deemix finishes the same track again and the file already exists in the playlist folder, Aurral keeps the existing file. It does not create a numbered copy.

## Upgrades

deemix can supply quality upgrades. Because its **Bitrate** setting fixes the quality that it delivers, Aurral compares that quality with the file that you have. Aurral skips deemix when it cannot deliver a better file. For example, deemix set to FLAC can upgrade an MP3, but deemix set to MP3 128 does not upgrade anything better than MP3 128. Aurral also checks each downloaded file against the quality profile, so an upgrade never replaces a file with a worse one.
