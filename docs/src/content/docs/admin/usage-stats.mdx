---
title: Usage stats
description: Anonymous usage stats you can choose to share with the Aurral project.
---

Usage stats tell us which features people use, so we know what to build, fix, and remove. They are off until an admin turns them on, and the totals are public at [stats.aurral.org](https://stats.aurral.org).

Turn them on or off in **Settings > General > Usage stats**. **What's sent** shows the next report exactly as aurral.org would receive it.

## What's sent

Every 3 days, Aurral sends one report with:

- The Aurral version, whether it runs in Docker, and the server's OS and CPU type.
- Rough sizes, such as 10k-99k tracks or 2-9 users. Counts are always ranges.
- Which integrations are connected, which sign-in methods are on, and which common settings are on.
- Where recommendations and listening history come from.
- Which download sources finished or failed downloads, and which playlist services were imported from.
- Which pages were opened, what kinds of devices, systems, and browsers opened them, and whether Aurral ran as an installed app.
- Which Subsonic apps connected, from a list of known apps.
- How many users use light, dark, or system appearance, and Aurral's theme, a preset, or a custom one.
- How many warnings and errors each part of Aurral logged.
- How many plugins are installed and turned on. Downloads, imports, warnings, and errors from plugins count together as plugins.

## What's never sent

Names, usernames, email addresses, IP addresses, hostnames, URLs, folder paths, API keys, plugin names, or anything about your music. There is no ID that links one report to the next. aurral.org doesn't store the address a report came from.

Forks and development builds never send reports.
