Use this converter when you cannot connect Spotify to Aurral. Your browser converts the file. It does not upload the file anywhere.

1. Export the playlist with [Exportify](https://exportify.net/).
2. Convert the downloaded `.csv` file below.
3. In Aurral, open **Library > Playlists**, open the create menu, and select **Import playlist > JSON file**.
4. Select the converted JSON file.

<SpotifyCsvConverter />

The converter reads Spotify column names such as `Track Name`, `Artist Name(s)`, and `Album Name`. It skips rows without an artist name and a track name.

For Spotify imports, JSON formats, retries, and file reuse, see [Playlist imports](/using/playlist-imports/).
